# README art

The SVGs in `docs/readme/` are generated by `gen.mjs`. `art.txt` is the bunker scene from the app's login screen (`display_bunker` in `main/SHARED_RESOURCES.py`), kept here so the art can be redrawn from the original.

```bash
cd docs/readme/source
npm i geist@1.3.1
pip install fonttools brotli
node gen.mjs
```

Each SVG has dark and light versions and respects `prefers-reduced-motion`.

## Fonts

The SVGs embed subsets of **Geist** and **Geist Mono** by Vercel, licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). The subsets keep the fonts' copyright and licence name records.
